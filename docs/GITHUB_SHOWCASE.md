# GitHub Project Showcase

## The Project in 30 Seconds

This project began as an attempt to discover trading strategies and ended by
showing why none of the tested ideas should become a bot. Its primary
contribution is the process: preregistration, outcome-blind QA, negative
controls, Holm correction, Bootstrap inference, replication, post-cost gates,
and explicit stopping rules.

## Technical Highlights

- modular Scientific Framework built on Freqtrade;
- thousands of historical experiments cataloged;
- isolated scientific instruments;
- auditable data acquisition through manifests and checksums;
- sealed Holdouts;
- human-readable reports paired with JSON and CSV Research Artifacts;
- negative decisions preserved in Scientific Ledgers;
- scientific cost used to terminate low-value Hypotheses early.

## A Representative Result

Discovery V3 H02 and H04 identified statistically measurable relationships, but
their gross effects were only 1.23 bp and 0.37 bp against cost assumptions of
30 bp and 15 bp. The project did not turn significance into marketing. Both
Hypotheses were rejected.
