# Support

This repository is a scientific and portfolio Research Artifact. It is not a
signal service, an approved strategy, or a commercial trading-support product.

## Where to Ask

- **Reproducible software bug:** open an issue using the bug template.
- **Maintenance improvement:** use the feature-request template.
- **Methodology review:** start a research discussion.
- **Vulnerability or exposed secret:** follow the [Security Policy](SECURITY.md).
- **General Freqtrade usage:** consult the
  [official Freqtrade documentation](https://www.freqtrade.io/en/stable/).

## What to Include

- operating system and Python version;
- commit SHA or release version;
- the smallest reproducing command;
- sanitized output;
- relevant files with all credentials removed;
- whether the concern is a software defect or a scientific disagreement.

## Out of Scope

- buy or sell recommendations;
- return guarantees;
- parameter selection;
- informal reopening of a rejected Hypothesis;
- support for live capital;
- review of configurations that contain secrets.
