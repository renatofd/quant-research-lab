# Suporte

Este projeto é um artefato científico e de portfólio, não um serviço de sinais,
uma estratégia aprovada ou suporte comercial de trading.

## Onde pedir ajuda

- **Bug reproduzível:** use o template de bug.
- **Melhoria de manutenção:** use o template de feature.
- **Auditoria metodológica:** abra uma discussão de pesquisa.
- **Vulnerabilidade ou segredo:** siga [SECURITY.md](SECURITY.md).
- **Uso geral do motor:** consulte a
  [documentação oficial do Freqtrade](https://www.freqtrade.io/).

## Inclua no pedido

- sistema operacional e versão do Python;
- commit ou versão;
- comando mínimo;
- saída sanitizada;
- arquivos relevantes sem credenciais;
- distinção entre bug de software e discordância científica.

## Fora de escopo

- recomendações de compra ou venda;
- garantia de retorno;
- escolha de parâmetros;
- reabertura informal de hipótese rejeitada;
- suporte a capital real;
- análise de configurações contendo segredos.
