## Interpretation Rules

Earlier reports record the Evidence available when they were issued. If two
records differ because the Research Pipeline advanced, the latest Scientific
Ledger is authoritative without erasing the historical decision.

For example, the audit that identified A08, A09, and A11 as not yet directly
tested predates the experiments that later closed those Hypotheses.

Markdown is the human-readable interface. JSON is the structured audit
interface, and HTML/CSV files are supporting Research Artifacts. A narrative
summary never overrides the corresponding structured decision.
