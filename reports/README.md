## Interpretação

Relatórios anteriores registram o conhecimento disponível no momento em que
foram emitidos. Quando houver divergência temporal, prevalece o ledger mais
recente sem apagar a decisão histórica. Em particular, a auditoria que apontou
A08, A09 e A11 como não testadas precede os experimentos que posteriormente as
encerraram.

Arquivos HTML e JSON são formatos auxiliares. O Markdown é a interface humana;
o JSON é a interface de auditoria.
