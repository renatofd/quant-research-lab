## [1.0.0] — 2026-07-25

### Added

- documentação pública completa e índices de pesquisa/relatórios;
- auditorias estrutural e de segurança;
- arquitetura, roadmap, histórico, lições e decisões de design;
- políticas de contribuição, conduta, suporte e segurança;
- templates de issue, PR e discussão;
- citação, notice e notas de release;
- regras de versionamento para código científico e artefatos agregados.

### Changed

- README reposicionado de bot upstream para laboratório científico;
- estrutura pública organizada sem mover artefatos históricos;
- configuração do Git ajustada para excluir dados, bancos, logs e segredos;
- automações de publicação específicas do upstream removidas.

### Removed

- logs de execução e caches Python locais;
- metadados de funding do upstream;
- workflows de deploy/pacotes que não pertencem ao laboratório.

### Scientific status

- nenhuma hipótese confirmada;
- nenhum bot aprovado;
- Discovery V3 encerrado com `CONCLUDED_NO_ROBUST_EDGE`;
- H01, H02, H03, H04, H09 e H10 rejeitadas;
- H05–H08 bloqueadas por dados indispensáveis ausentes.
