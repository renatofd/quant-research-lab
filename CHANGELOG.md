# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

- independent public review;
- maintenance of documentation and Reproducibility;
- no new experiment without materially new data and a new Research Protocol.

## [1.0.0] — 2026-07-25

### Added

- public project documentation and curated research/report indexes;
- structural and security audits;
- architecture, Roadmap, history, lessons learned, and design decisions;
- contribution, conduct, support, and security policies;
- GitHub issue, pull request, and discussion templates;
- citation metadata, attribution notice, and release notes;
- version-control rules for source code and aggregate Research Artifacts.

### Changed

- repositioned the README from an upstream trading-bot introduction to a
  Scientific Framework;
- organized the public repository without relocating historical Research
  Artifacts;
- expanded Git exclusions for raw data, databases, logs, caches, and secrets;
- removed upstream-specific publishing automation.

### Removed

- local execution logs and Python caches;
- upstream funding metadata;
- deployment and package-maintenance workflows that did not belong to the
  research project.

### Scientific Status

- zero confirmed Hypotheses;
- no approved trading bot;
- Discovery V3 concluded with `CONCLUDED_NO_ROBUST_EDGE`;
- H01, H02, H03, H04, H09, and H10 rejected;
- H05–H08 blocked because required data was unavailable.
